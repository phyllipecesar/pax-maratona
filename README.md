# Pax na Maratona

Formulário de contato da Pax para os maratonistas da Final Brasileira da Maratona SBC de Programação 2026 (Uberlândia).

- `index.html` — formulário (três etapas, autocomplete dos times finalistas). Carrega a lista de nomes com IDs direto da planilha via Apps Script e grava cada resposta na aba Respostas.
- `fonts/` — tipografia da marca Pax.
- `apps-script.gs` — código do Apps Script vinculado à planilha (receptor das respostas e gerador de IDs).

Publicado via GitHub Pages.
